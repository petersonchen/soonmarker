soonmarker

模式：

影片庫

已選 0 支影片
沒有符合的 Episode 或 Marker

匯出

匯出 Episode 或 backlog 的全部 Marker 與影片順序。完整備份包含所有 Episode、影片、Marker 與設定。

已複製

匯入

貼上 v2 JSON、CSV 或從試算表複製的表格，也可選擇檔案。先預覽，再確認匯入。

表格第一列：url、timecode、note，可選填 title。Timecode 支援 HH:MM:SS、MM:SS 或秒數；每列是一筆 Marker。

設定

顯示

個

未搜尋時依名稱由大到小顯示；0 為全部。搜尋不受限制，backlog 不計入數量。

播放

秒

從 Marker 前 0–60 秒開始，0 表示不提前。適用於 popup 與管理頁的 CUE／PLAY、EDIT 試播，不影響「跳到時間」。

管理頁切換影片時沿用播放分頁；關閉後優先使用已開啟的影片分頁，否則開新分頁。

快捷鍵

微調 Marker 秒數

  1. 將模式切換為 EDIT，點選要調整的 Marker 的 Timecode。
  2. 按 ↑ 或 ↓ 加減 1 秒。
  3. 按 Shift+Enter 儲存，並在背景分頁從該時間播放；畫面留在管理頁，游標仍在 Timecode 欄位。
  4. 邊聽邊重複步驟 2、3，直到時間正確。
  5. 按 Enter 或點選其他地方結束編輯。

影片頁

未設定不開 popup，直接將目前位置儲存為 Marker

管理頁 EDIT 模式

↑／↓在 Timecode 欄位加減 1 秒，尚未儲存
Enter儲存並結束編輯
Shift+Enter在 Timecode 或標題欄位儲存，並在背景分頁從該 Marker 播放；游標留在欄位中
Shift+點選 ▶在背景分頁從該 Marker 播放

popup

Enter（Marker 說明）儲存目前位置
Enter（跳到時間）跳到該時間並播放
↑／↓（Marker 的 Timecode）加減 1 秒，按 Enter 儲存

新增 Episode

加入 Episode

保留影片在其他 Episode 的歸屬，Marker 共用。

從所選 Episode 移除

依勾選位置移除影片歸屬，保留影片、Marker 與其他 Episode 的歸屬。沒有其他歸屬時回到 backlog。
